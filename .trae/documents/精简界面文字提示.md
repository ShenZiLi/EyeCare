# 精简界面文字提示

## 概要

界面当前存在大量静态说明文字（常驻提示、副标题、脚注、氛围文案），信息密度过高。本次改动删除所有冗余的静态文字，仅保留：控件标签、按钮、动态错误/警告/状态原因、以及区分预览与真实提醒的必要标识。

## 现状分析

文字提示分布在 4 个文件：

- [App.tsx](file:///Users/shen/Studio/Code/EyeCare/app/renderer/App.tsx)：侧边栏隐私说明、页头常驻自动保存状态（5 态文案）、概览脚注、预览反馈（4 种文案）、两个弹窗的长说明
- [Settings.tsx](file:///Users/shen/Studio/Code/EyeCare/app/renderer/Settings.tsx)：3 处 Section 描述、6 张选择卡片的副文案、2 处脚注、字段范围提示、3 处 Toggle 提示、2 处 preview-bar 提示
- [Overlay.tsx](file:///Users/shen/Studio/Code/EyeCare/app/renderer/Overlay.tsx)：休息蒙版的描述段落、底部快捷键提示
- [styles.css](file:///Users/shen/Studio/Code/EyeCare/app/renderer/styles.css)：对应的 `.sidebar-note`、`.quiet-note` 等样式

e2e 测试仅 3 处依赖将被改动的文案（L116 `#rest-description`、L194 `'预览已关闭，不影响实际计时'`、L322 `'已自动保存并生效'`），其余断言（按钮名、radio 名、`'重试自动保存'`、`'仅声音模式需要保持开启。'` 等）不受影响。

## 改动方案

### 1. App.tsx

| 位置 | 处理 |
|---|---|
| 侧边栏 `sidebar-note`（"只检测空闲状态/不记录输入内容"） | **删除**整块（与通用设置页说明重复） |
| 页头 `autosave-status` 默认态"修改后自动保存并生效" | **删除**——空闲时不渲染任何文字 |
| pending"正在自动保存…" / failure"自动保存未完成，输入已保留。" / unsaved"标记项尚未生效…" | **保留**（动态状态，用户需知道输入是否生效） |
| saved"已自动保存并生效" | **删除**（保存成功是预期行为） |
| settingError Notice 内 hint"你的输入已保留…" | **删除**（主文案+重试按钮已足够） |
| 预览 outcome 反馈 4 种文案 | **统一为 2 种**：failed→'预览失败'，cancelled/automatic/其余→'预览已结束' |
| 概览 quiet-note"关闭窗口后在托盘继续运行…" | **删除** |
| 预览弹窗说明+2 个 Notice | **压缩为一句**："预览不影响计时；闪屏或蒙版会短暂覆盖全屏。" |
| 恢复默认弹窗说明 | **压缩为**："恢复全部默认设置，立即生效。" |
| `action-reason`（"立即提醒"禁用时的状态原因）、warnings/error Notice、倒计时与状态 pill | **保留**（动态必要内容） |

### 2. Settings.tsx

| 位置 | 处理 |
|---|---|
| Section 描述 ×3（"累计使用时间…"等） | **删除**（不再传 description） |
| 触发条件卡片副文案 ×2（"鼠标或键盘有活动时累计。"等） | **删除** |
| 提醒方式卡片副文案 ×4（"深色蒙版，2 秒后结束"等） | **删除** |
| quiet-note ×2（"修改触发条件会重新计时…"、"本地运行…"） | **删除** |
| Numeric 字段 hint（"1–240 分钟"） | **删除**（min/max 已在输入框约束，错误提示仍在） |
| 声音 Toggle hint | 仅保留禁用原因**"仅声音模式需要保持开启。"**；删除"内置轻柔提示音，每轮只播放一次。"（e2e L287 依赖前者，保持通过） |

### 3. Overlay.tsx（休息蒙版）

| 位置 | 处理 |
|---|---|
| 描述段 `<p id="rest-description">`（两种文案） | **删除**，同时移除 `aria-describedby` 属性 |

| h1 提醒语、"知道了"按钮、动态错误 | **保留** |

### 4. styles.css

- 删除 `.sidebar-note`、`.sidebar-note span`、`.quiet-note` 规则及 L179 媒体查询中的 `.sidebar-note` 引用

- `.hint`、`.toggle-row .hint` 保留（action-reason 与禁用原因仍在用）

### 5. e2e 测试更新（tests/e2e/desktop.test.ts）

## 假设与决策

- "必要内容"定义为：控件标签、按钮、动态错误/警告/状态原因、预览标识。静态说明、氛围文案、重复安抚一律删除。
- Brand 副标题"让眼睛歇一会儿"保留（品牌语，非提示）。
- 无效输入（unsaved）与保存失败提示保留——用户需知道输入未生效，这是 autosave 模式的核心反馈。
- 蒙版页保留 eyebrow 以区分预览/真实提醒。

## 验证与交付

2. `npm run test:e2e`（全部通过）
3. 本地 git 提交
4. `npm run package` 重新打包并重启应用（遵循项目工作流规则：改动后重启应用供用户查看）
